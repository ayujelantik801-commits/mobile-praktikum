# Analisis Aplikasi Permintaan Mobile

## 1. Aplikasi yang Diamati
Aplikasi manajemen tugas dan aktivitas harian mahasiswa.

## 2. Pengguna
Mahasiswa dan dosen pengampu mata kuliah pemrograman mobile.

## 3. Tiga Fitur Utama
- Pencatatan tugas harian (To-Do List)
- Pengingat tenggat waktu tugas
- Riwayat status pengerjaan tugas

## 4. Usulan Perbaikan
Menambahkan mode gelap (Dark Mode) agar lebih nyaman digunakan pada malam hari.

# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi latihan untuk memahami dasar-dasar pengembangan aplikasi mobile menggunakan Flutter. Proyek ini dibuat sebagai bagian dari tugas praktikum mata kuliah Pemrograman Berbasis Mobile.

## Pengembang
Nama panggilan / akun GitHub: ayujelantik801

## Status
Proyek awal perkuliahan.

## Tujuan
Aplikasi ini dibuat sebagai latihan pengembangan aplikasi mobile menggunakan Flutter, sekaligus sarana mempraktikkan penggunaan Git dan GitHub dalam alur kerja kolaboratif.

## Rencana Fitur
1. Halaman utama yang menampilkan daftar data/konten utama aplikasi.
2. Fitur pencarian untuk memudahkan pengguna menemukan data yang dicari.
3. Fitur tambah/simpan data baru dari pengguna.

## Cara Menjalankan
Proyek belum sepenuhnya diverifikasi dapat berjalan hingga tahap akhir. Langkah yang direncanakan:
```
flutter pub get
flutter run
```
